`docs/` must stay in sync with code — update it in the same change, not as a follow-up.

Every change bumps the version (`MAJOR.MINOR.PATCH`) in the same change as the code and docs:
- **PATCH**: bug fixes, internal improvements, small feature additions or refinements (e.g. adding badges/labels, minor UI tweaks, small visual enhancements).
- **MINOR**: substantial or headline features.
- **MAJOR**: breaking architectural changes or major redesigns.
