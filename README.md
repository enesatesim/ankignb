# **AnkiGNB**

### *The fastest way to export Gemini Notebook flashcards into Anki.*

> AnkiGNB is a fork of [AnkiNLM](https://github.com/maialks/ankinlm) by lkmss, updated for **Gemini Notebook** (`notebook.google.com`), the new name of Google NotebookLM.


## **Overview**

**AnkiGNB** is a lightweight browser extension that adds **Copy** and **Download** buttons to the footer of a Flashcards or Quiz artifact in the Gemini Notebook Studio panel.
With a single click, you get a fully formatted file ready for import into Anki — no rewriting, no manual cleanup.

---

## **Features**

* One-click export of flashcards and quizzes
* Copy or download support
* Compatible with Anki field mapping
* Optimized for math-heavy flashcards
* Preserves LaTeX syntax (`\sin(x)`, `\frac{a}{b}`, etc.)
* Lightweight and privacy-friendly

## **Recommended Setup**

To render mathematical expressions in Anki, use an add-on capable of interpreting LaTeX or MathJax.

**Recommended:**
**Better Markdown Anki** — Add-on ID **2100166052**

This add-on has shown the most consistent rendering results with files generated by AnkiGNB.

> Note: AnkiGNB is not affiliated with or responsible for external add-ons. Any LaTeX-compatible template or renderer will work.

## **How to Use**

1. Open a notebook at [notebook.google.com](https://notebook.google.com) and open a generated **Flashcards** or **Quiz** artifact in the Studio panel.
2. Look at the artifact's footer, next to the thumbs up / down buttons.
3. Click **Download** (or **Copy**). In a narrow panel the buttons show only their icons; hover for a tooltip.
4. Open Anki and import the file.
5. Map fields as:

   * **Field 1 → Front**
   * **Field 2 → Back**
6. Choose your deck and finish the import.

The downloaded file is called `flashcards.csv` but is **tab-separated**; Anki detects this automatically. For quizzes, Front is the question and Back is the correct answer.

---

## **Importing Into Anki**

### **Anki Desktop (Windows / macOS / Linux)**

1. Go to **File → Import**
2. Select the file
3. Set field mapping: **Field 1 = Front**, **Field 2 = Back**
4. Confirm the import

### **AnkiMobile / AnkiDroid**

1. Transfer or paste the file to your device
2. Import directly or via AnkiWeb sync

### **AnkiWeb**

1. Open or create a deck
2. Click **Add → Import File**

## **Installation**

### **Chrome / Chromium (from source)**

AnkiGNB is not on the Chrome Web Store yet.

1. Install [Node.js](https://nodejs.org), then run `npm install` and `npm run build` in this folder.
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick `.output/chrome-mv3`.
