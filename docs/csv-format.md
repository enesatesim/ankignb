# CSV Format

Generated by `generateCsvString()` and `createCsvBlob()` in `src/utils/utils.ts:48`.

## Delimiter and Encoding

- **Delimiter: TAB (`\t`)**, one card per line (`\n`). Despite the `.csv` extension the output is tab-separated — choose tab delimiter (or let Anki auto-detect) on import.
- **Encoding:** UTF-8 with BOM (`\uFEFF` prefix, `text/csv;charset=utf-8`).
- **Filename:** `flashcards.csv` (set in `src/entrypoints/content/index.ts:21`).

## Rows

- Flashcards (`src/types.ts:8`): `{ f, b }` → `front<TAB>back`.
- Quiz (`src/types.ts:1`): `{ question, answerOptions[] }` → `question<TAB>correct-option-text`, where correct = first `answerOptions.find(opt => opt.isCorrect)`. Questions with no correct option are skipped.

## Escaping

`escapeCsvField()` (`src/utils/utils.ts:40`):


1. `"` → `""`
2. If field contains tab, newline, or `"` → wrap in `"..."`

Commas are **not** quoted (safe because the delimiter is tab, not comma).

## LaTeX

Fields are passed through verbatim — `\sin(x)`, `\frac{a}{b}` etc. are preserved for Anki-side MathJax/LaTeX renderers. No Markdown-to-HTML conversion is done.
